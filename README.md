## 🚀 About The Project

Shows the days weather in the format below :

    ✅ Nairobi, Kenya: 19C, Sunny
    
    00:00: 15C, Partly Cloudy (15%)
    01:00: 14C, Partly Cloudy (16%)
    02:00: 14C, Cloudy (22%)

Provide a location to get custom weather predictions for other locations:

`$ sun Mombasa`
